Request Custody (Free)

Two routes to free custody, one artefact each. A wallet may use both routes — but no wallet, and no X name, is ever granted the same route twice.

Route A — Agent ID custodians · 500 free

If your wallet holds a Binance Agent ID, you are, in the department's judgement, a descendant of the excavated civilisation — and one artefact is reserved in your name. Connect and file the request.

Route B — Verified X custodians · 250 free

No Agent ID required. Your X account must be verified (blue check). Publish a short notice containing this page's address and your file reference — the last six characters of your wallet address, issued below once you connect — then file the notice's link here.
